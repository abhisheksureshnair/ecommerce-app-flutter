## ✨ Features
- **Modern UI**: Clean, glassmorphic design inspired by premium luxury apps.
- **Dynamic Filtering**: Sticky category headers and seamless product exploration.
- **Real-time Sync**: Synchronized backend using a robust Node.js API.
- **Secure Backend**: Integrated authentication and secure data handling.

## 🚀 Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- [Node.js](https://nodejs.org/)

### Setup Instructions
1. **Clone the project**
   ```bash
   git clone https://github.com/abhisheksureshnair/ecommerce-app-flutter.git
   ```

2. **Install Flutter dependencies**
   ```bash
   cd luxentia_ecommerce_frontend
   flutter pub get
   ```

3. **Run the app**
   ```bash
   flutter run
   ```
